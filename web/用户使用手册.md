# 羽毛球视频处理使用手册

## 1. 功能概览

本服务用于将一段羽毛球视频上传到服务器，自动识别视频中的有效片段并切割为多个 MP4 文件。处理完成后，用户可以预览原视频、筛选切割结果、单独或批量下载片段，并在历史任务中重新查看以前的处理结果。

主要功能包括：

- 上传常见视频格式的羽毛球视频
- 设置需要保留的最短片段时长
- 自动识别并切割有效片段
- 查看片段数量、总大小和平均时长
- 按片段时长筛选结果
- 单独下载或批量下载勾选的片段
- 查看并重新载入历史处理任务

## 2. 访问服务

### 公网访问

使用手机或电脑浏览器打开服务管理员提供的访问地址（域名或公网 IP 均可，如 `https://your-domain.com/` 或 `http://服务器IP/`）。

建议连接稳定网络后上传大文件。公网访问的上传速度会受到用户网络带宽影响。

## 3. 上传视频

1. 打开首页后，点击“点击或拖拽上传视频”区域。
2. 在手机相册或文件管理器中选择一段视频。
3. 等待上传进度条完成。
4. 上传成功后，页面会显示：
   - 原视频预览播放器
   - 文件名
   - 文件大小
   - 处理参数设置

支持的文件格式为 MP4、MOV、QT、M4V、3GP、AVI、MKV、FLV 和 WMV，单个视频默认最大为 500 MB。特别兼容 iPhone 相册裁剪后导出的 QuickTime（.qt / .mov / .m4v）视频。

## 4. 设置处理参数

上传完成后，可在“处理参数”中填写“多少秒以上的片段才保留”。

- 默认值为 `5` 秒。
- 设为 `0`：保留服务识别到的所有片段。
- 建议设置为 `5～10` 秒：通常可过滤较短、内容不完整的片段。

该设置在视频切割前生效，未达到该时长的片段不会出现在本次处理结果中。

## 5. 开始处理视频

1. 确认参数后，点击“开始处理”。
2. 页面会显示“处理中，请耐心等待”。
3. 请保持当前页面打开，并等待处理完成。
4. 视频较长时，处理可能需要数分钟，具体时间取决于视频时长和电脑性能。

处理完成后，按钮会变为“重新处理”。如需更换最短片段时长，可修改参数后再次点击该按钮。

## 6. 查看处理结果

处理成功后，页面会显示“处理结果”区域，包括：

- 片段数：成功输出的视频片段数量
- 总大小：全部片段的文件大小之和
- 平均时长：全部片段的平均播放时长

每个结果项都包含：

- 文件名
- 视频时长
- 文件大小
- 勾选框
- 单独下载按钮

如果显示“没有符合条件的片段”，请尝试把处理参数中的最短时长调小后重新处理。

## 7. 筛选片段

处理结果上方可使用“只显示多少秒以上”的筛选条件：

1. 输入最短显示时长，例如 `10`。
2. 点击“应用筛选”。
3. 页面只显示时长不低于该值的已生成片段。

这个筛选仅影响页面显示和批量选择，不会删除任何已经生成的文件。点击“重置”可恢复显示全部结果。

## 8. 下载并保存视频

### 下载单个片段

点击任意片段右侧的下载按钮即可下载该视频。

### 批量下载片段

1. 勾选需要下载的视频片段，或点击“全选”。
2. 点击“下载勾选”。
3. 浏览器会依次发起下载请求。

手机浏览器通常会把文件保存到“下载”或“文件”位置。浏览器不能直接自动写入手机相册：

- iPhone：在 Safari 或“文件”中打开已下载的视频，点击“分享”，再选择“存储视频”。
- Android：下载完成后通常可从通知栏或“下载”目录打开；不同手机系统可选择“保存到相册”或“移动到相册”。

若浏览器提示是否允许多个下载，请选择允许。

## 9. 查看历史任务

页面底部的“历史任务”会展示最近处理过且存在结果的任务。

每条历史任务会显示：

- 任务编号
- 已生成片段数量
- 片段总时长

点击右侧的文件夹按钮，可重新载入该任务的处理结果，并继续筛选、勾选和下载。

历史任务仅显示仍保存在服务端的结果文件；如果管理员清理了文件，任务将不再显示或无法下载。

## 10. 常见问题

### 上传后提示“文件类型不允许”

请确认视频扩展名为 MP4、MOV、QT、M4V、3GP、AVI、MKV、FLV 或 WMV，并且文件确实是视频文件。若文件来自 iPhone 相册或剪辑工具，可放心使用 .qt、.mov、.m4v 格式。

### 上传失败或中断

检查网络连接和文件大小。较大的视频在移动网络或不稳定 Wi-Fi 下更容易失败，建议连接稳定 Wi-Fi 后重试。

### 点击“开始处理”后等待很久

视频处理在运行服务的电脑上执行，视频越长、分辨率越高，处理时间越长。处理期间请不要关闭服务进程或刷新页面。

### 没有生成任何片段

可能是视频中没有识别到有效羽毛球活动，也可能是最短片段时长设置过高。可将参数调低到 `0` 或 `3` 秒后重新处理。

### 无法打开服务

请检查网络连接后重新访问服务管理员提供的地址。如果仍无法访问，请联系服务管理员确认公网服务是否正常运行。

### 下载后找不到视频

请在手机浏览器的下载记录或文件管理器的“下载”目录中查找。iPhone 通常需要从“文件”中打开后再手动存储到相册。
