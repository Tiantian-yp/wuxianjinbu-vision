羽毛球视频处理使用手册

上传视频、自动识别切割、筛选并下载精彩片段。

1. 功能概览

本服务用于上传羽毛球视频，自动识别视频中的有效片段并切割为多个 MP4 文件。处理完成后，可预览原视频、筛选切割结果、单独或批量下载片段，并重新查看历史任务。

  • 上传常见视频格式的羽毛球视频
  • 设置需要保留的最短片段时长
  • 自动识别并切割有效片段
  • 查看片段数量、总大小和平均时长
  • 按片段时长筛选、下载和重新查看历史任务

2. 访问服务

使用手机或电脑浏览器访问：

{{ site_url }}/

建议连接稳定的 Wi-Fi 后上传大文件。公网访问会受网络带宽影响，上传时间可能较长。

3. 上传视频

  1. 在首页点击“点击或拖拽上传视频”。
  2. 在手机相册或文件管理器中选择视频。
  3. 等待上传进度条完成。
  4. 上传成功后，查看原视频预览、文件名和文件大小。

支持 MP4、MOV、QT、M4V、3GP、AVI、MKV、FLV 和 WMV 格式；单个视频最大 500 MB。特别兼容 iPhone 相册裁剪后导出的 QuickTime（.qt / .mov / .m4v）视频。

4. 设置处理参数

上传完成后，可设置“多少秒以上的片段才保留”。默认值为 5 秒。

  • 设置为 0：保留系统识别出的所有片段。
  • 建议设置为 5～10 秒：通常可过滤较短或不完整的片段。

5. 开始处理视频

  1. 确认参数后，点击“开始处理”。
  2. 页面显示“处理中，请耐心等待”后，请保持页面打开。
  3. 处理完成后，结果将显示在“处理结果”区域。

视频越长、分辨率越高，处理所需时间越长。需要调整最短片段时长时，可修改参数后点击“重新处理”。

6. 查看和筛选结果

处理结果会显示片段数、总大小和平均时长。每个片段包含文件名、视频时长、文件大小、选择框和单独下载按钮。

如需只查看较长片段，在“只显示多少秒以上”中输入时长，点击“应用筛选”。此操作仅改变当前显示内容，不会删除已生成的视频文件。

7. 下载并保存视频

下载单个片段

点击片段右侧的下载按钮即可下载。

批量下载片段

  1. 勾选需要的视频片段，或使用“全选”。
  2. 点击“下载勾选”。
  3. 浏览器会依次下载所选文件。

手机浏览器不能直接自动写入相册：

  • iPhone：在 Safari 或“文件”中打开下载的视频，点击“分享”，选择“存储视频”。
  • Android：从通知栏或“下载”目录打开文件，并按手机系统提示保存或移动到相册。

8. 查看历史任务

页面底部的“历史任务”展示仍保存有处理结果的任务。点击任务右侧的文件夹按钮，可重新载入该任务的结果，继续筛选、勾选和下载。

9. 常见问题

上传后提示“文件类型不允许”

请确认文件后缀为 MP4、MOV、QT、M4V、3GP、AVI、MKV、FLV 或 WMV，且文件确实是视频。若文件来自 iPhone 相册或剪辑工具，可放心使用 .qt、.mov、.m4v 格式。

没有生成片段

可能未识别到有效羽毛球活动，或最短片段时长设置过高。可将参数调低到 0 或 3 秒后重新处理。

下载后找不到视频

请在浏览器下载记录或手机文件管理器的“下载”目录中查找。iPhone 通常需要从“文件”中打开后再手动存储到相册。
